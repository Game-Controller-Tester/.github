## 📖 Introduction
Controller Tester for Windows is a game controller tester that shows exactly what your gamepad is sending to your PC. Every button press lights up, both analog sticks are mapped with a live deadzone readout, triggers report their travel, and a vibration test confirms the rumble motors. It is the fast way to check a new pad, hunt down stick drift, or confirm a button before a tournament. Working with Xbox, PlayStation, and generic controllers, this input tester keeps diagnosis simple and visual.

## ✨ Highlights

### Check input
- **Button mapping** — See each button register the instant you press it.
- **Trigger travel** — Read analog trigger values from light to full.
- **Live stick view** — Watch both sticks move in real time.

### Diagnose issues
- **Deadzone and drift** — Spot deadzone problems and stick drift at a glance.
- **Vibration test** — Confirm the rumble motors fire correctly.
- **Broad support** — Xbox, PlayStation, and generic controllers.
